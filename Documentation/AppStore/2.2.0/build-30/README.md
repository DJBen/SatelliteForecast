## Changes

Home places its sky panel beside upcoming passes on wide windows. Pass charts
keep actions and event times beside the sky. Satellite and pass browsing gain
list/detail layouts, station/category cards use grids, and settings, location
and alarm tasks have bounded widths. Alarm editing uses a form sheet. Onboarding
composes its preview and introduction side by side on wide iPads.

Charts use denser real catalog stars, Retina rendering, finer orbit paths and
higher-resolution Milky Way textures. Shared actions use consistent touch-target
sizes, dark surfaces and a muted cyan accent. Keyboard shortcuts cover tabs,
search and alarm save/cancel. Both app and widget include iPad device family 2.
